## What This Page Will Cover

A structured comparison of existing adaptive reading tools and research systems, evaluated against the key attributes relevant to this thesis:

| Attribute | Why It Matters |
|---|---|
| Modularity | Can sensing, decision, and UI layers be swapped? |
| Hardware support | Does it integrate with eye tracking hardware? |
| Researcher control | Can researchers observe and intervene in real time? |
| Intervention types | What adaptations are supported? |
| Extensibility | Can new decision sources be plugged in? |
| Experimental workflow | Is it designed for controlled studies? |
| Open source | Is the implementation available for comparison? |
