## Recommended Reading Order

1. Read the provider integration guide to understand the transport and message flow.
2. Read the black-box contract to understand the boundary and example payloads.
3. Use the backend intervention module catalogue at runtime to align generated interventions with backend validation.
4. If you are adding a new module type (not just an AI decision provider), read the adding-a-new-module guide.
5. Use the roadmap page to understand what has been implemented and what remains as future work.

## Proof this path works

The integration path is not hypothetical: a concurrent, independent thesis project (Reading the Struggle) connected its reading-difficulty analysis pipeline through this contract, with no changes to the platform core, and served as the live analysis source for the platform's own evaluation. The mock decision-maker and mock eye-movement analyzer under [Running the System](/running-the-system/) give you working reference implementations to develop against.
