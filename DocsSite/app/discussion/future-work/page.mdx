# Future Work

Each direction answers a limitation rather than opening a new front:

1. **Re-evaluate the revised context restore with readers**, and unbundle the confound by crossing the restore with the highlight cue on and off. The evidence so far suggests the highlight is the larger contributor to recovery; only an unbundled comparison settles it.
2. **Run the automated decision path at scale**: a real decision model, autonomous mode, many sessions, and a networked provider, turning the single validation run into a measured campaign.
3. **The controlled efficacy study** the thesis deliberately left out: a properly powered human-subjects study testing whether specific interventions improve reading, run on the platform's reproducible records.
4. **Strengthen the modularity claim from outside**: invite decision and analysis providers beyond the single collaborator, and add webcam or other multimodal sources behind the existing sensing adapter.
5. **Replace the hand-tuned line-bias constant with a Kalman filter**, giving the gaze mapping a principled estimate of its own uncertainty instead of a fixed discount.

For teams picking any of these up: start with [Adding a New Module](/integration/adding-a-new-module/) and the [Provider Protocol](/integration/provider-protocol/); the mock providers give you something to develop against on day one.
