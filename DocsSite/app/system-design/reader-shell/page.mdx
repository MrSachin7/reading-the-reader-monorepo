## What This Page Will Cover

The Reader Shell is the participant-facing reading surface. The Researcher Mirror is its real-time reflection on a secondary screen. Together they form the UI layer of the adaptive system.

### Topics

- Reader Shell architecture: how Markdown content is rendered and how visual presets are applied
- How interventions arrive at the frontend: WebSocket envelope → Redux → component re-render
- Context preservation from the frontend perspective: anchor tracking, smooth scroll
- Researcher Mirror: how it stays in sync with the participant view
- Session health indicators: sample rate, validity, latency shown to the researcher
- Manual intervention controls available in the researcher interface
