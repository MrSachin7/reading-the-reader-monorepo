# System Design

This section documents what was built and why it was built that way. It covers the full architecture — from the sensing pipeline through decision strategies and intervention execution to the researcher UI — and records the design decisions made at each layer.

This is the Methods section of the thesis. Every design choice here should be traceable back to a requirement in [Research Design](/research-design/).
