# Reading the Struggle

This folder is now part of the `reading-the-reader` monorepo.

It was forked from:
[https://lab.compute.dtu.dk/rtr/reading-the-struggle.git](https://lab.compute.dtu.dk/rtr/reading-the-struggle.git)

This repository contains ongoing master thesis work focused on reading behavior,
eye-tracking-derived features, and analysis pipelines for studying reading
struggle and related cognitive patterns.

This is the ongoing master thesis project of:

- Katarina Kraljevic (`s243906@student.dtu.dk`)
- Sree Keerthi Desu (`s243933@student.dtu.dk`)

The folder currently includes:

- `code/` for preprocessing, prediction, and model training scripts
- `code/notebooks/` for exploratory data analysis and experiments
- `data/` for project datasets and intermediate artifacts
- `plots/` for generated visualizations and analysis outputs
- `connector/` for integration-related components built by us to connect this
  project to the `reading-the-reader` app, rather than code maintained on the
  original project side

Notable scripts in `code/` include training workflows for cognitive load and
reading style models, together with preprocessing and prediction utilities.

This copy is maintained inside the monorepo for continued thesis development
and integration with the broader `reading-the-reader` project.
