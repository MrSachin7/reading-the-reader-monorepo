# Paper Astra

Independent preparation for a paper based on **Reading the Reader: Adaptive Reading Systems: A Modular Software Architecture**, by Sachin Baral and Satish Gurung.

The first complete paper draft is [main.pdf](main.pdf), with editable LaTeX in [main.tex](main.tex). It uses the official ACM single-column review manuscript style as specified in the verified ETRA instructions. This is an internal author draft, with factual confirmation items documented in [author-notes.md](author-notes.md). No deadlines are imposed.

The review started from `Master-Thesis-Report`, the implementation, and the original experiment exports. **`paper-fable`, `paper-sol`, and `paper` were not read or used.** No sub-agents were used. Application code, thesis text, and original datasets were not edited.

The paper presents a **researcher-operated, modular instrument for gaze-contingent reading experiments**, with context restoration as a case study in making intervention behaviour inspectable. The existing evidence supports a systems contribution; it does not establish improved reading performance. The earlier independent review remains available in [review.md](review.md).

## Build the PDF

From this folder, run:

```sh
make
```

This regenerates tables from the audited JSON, runs `latexmk`/pdfLaTeX/BibTeX, and copies the compiled PDF to `paper-astra/main.pdf`. Intermediate files stay in ignored `build/`. Requirements: Python 3.10+, `make`, and a TeX installation containing `acmart`, `latexmk`, and TikZ. The tested installation is TeX Live 2026 with `acmart` 2.16. No Python third-party packages are needed.

To recompute the evidence from the original data and then rebuild:

```sh
make audit
make
```

Formatting research and the distinction between this internal draft and a blind submission are recorded in [formatting-notes.md](formatting-notes.md). Quantitative tables and headline macros are generated by [build_paper_assets.py](analysis/build_paper_assets.py); [generated/manifest.json](generated/manifest.json) records the source audit hash.

The delivered draft has **13 pages, a 145-word abstract, 10 references, four tables, and one vector system diagram**. All pages were rendered and visually inspected. The final build has no unresolved citations/references or overfull boxes, all fonts are embedded, and all 20 original evidence-file hashes match the audit. Participant-procedure and version-provenance limitations remain marked for factual author review.

Reproduce the audit from the repository root:

```sh
python3 paper-astra/analysis/audit_evidence.py
```

It explicitly separates the eight context-preservation sessions from the additional advisory session, verifies telemetry pairing, and writes only under `paper-astra/analysis/outputs`. It does not use the existing pickle caches. Participant labels reproduce the four-person ordering used by the thesis tables; the outputs omit participant names and demographic fields. This is not a general-purpose anonymisation or data-release tool.
